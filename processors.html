Hardware Topology Comparison

In this project, we evaluate Trotter error scaling across two distinct NISQ hardware layouts:
• Processor A (Linear 1D Topology): Features lower single and two-qubit gate error rates, but requires expensive SWAP gate routing for long-range interactions.
• Processor B (All-to-All Topology): Eliminates routing overhead, but suffers from elevated multi-qubit crosstalk and higher gate error rates.
